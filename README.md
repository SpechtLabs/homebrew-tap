# Specht Labs Homebrew Tap

Homebrew casks for [Specht Labs](https://github.com/SpechtLabs) command-line tools. Each cask is built and published automatically on the project's release.

## Install

```shell
brew install spechtlabs/tap/kush
```

That adds this tap and installs the cask in one step, so a later `brew upgrade` keeps it current. To add the tap on its own:

```shell
brew tap spechtlabs/tap
```

## Packages

### kush

Ephemeral, isolated kube-context subshells. `kush prod` drops you into a shell pinned to a single Kubernetes context through a private, throwaway kubeconfig that is deleted when you exit, so a prod shell in one terminal can never reach the dev cluster in another.

```shell
brew install spechtlabs/tap/kush
```

- Source: <https://github.com/SpechtLabs/kush>
- Docs: <https://kush.specht-labs.de>

## Maintenance

The files under `Casks/` are generated by [GoReleaser](https://goreleaser.com) during each release. Don't edit them by hand; they are overwritten on the next release.
